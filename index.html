PROJECT 01 Closed-Loop Control System

Realization of a PID Algorithm for DC Motor Speed Control

Developed an autonomous closed-loop PID control system using Arduino to regulate DC motor speed dynamically. The system measures instantaneous rotational speed via encoder feedback, compares it against a desired target setpoint, and computes continuous error corrections using tuned proportional, integral, and derivative gains.

  • Real-time Closed-Loop Error Correction: Continuously computes deviation between target RPM and optical encoder feedback.
  • Parameter Tuning: Rigorously calibrated Kp, Ki, and Kd coefficients to eliminate steady-state error and suppress overshoot.
  • Performance Analysis: Evaluated system transient response, rise time, and settling stability using speed-vs-time graphs and error metrics.

PROJECT 02 Real-Time Embedded & FreeRTOS

Self-Balancing Boat Stabilization System

Developed an active marine vehicle stabilization platform powered by an ESP32 microcontroller, MPU6050 6-axis inertial measurement unit (IMU), and a high-precision stepper motor counterweight mechanism. Leveraged FreeRTOS for preemptive multi-tasking to guarantee deterministic sensor polling, filtering, and rapid motor actuation.

  • FreeRTOS Multitasking Architecture: Partitioned firmware into independent concurrent tasks for IMU acquisition, attitude calculation, and stepper control.
  • I2C Sensor Bus Interfacing: Read angular velocity and linear acceleration from MPU6050 over I2C to calculate continuous roll angles.
  • Automatic Dynamic Roll Stabilization: Actuated a stepper motor counter-torque arm in real time based on measured roll deviation to keep the hull level.

PID Algorithm Implementation Highlights
  • Discrete PID Equation: Computed control output using u(t) = Kp*e(t) + Ki*∫e(t)dt + Kd*(de/dt) computed over strict 10ms sampling periods.
  • Anti-Windup Protection: Clamped integral accumulator to prevent actuator saturation and excessive overshoot during step changes.
  • Tuning Methodology: Systematic manual tuning of Kp, Ki, and Kd parameters to achieve near-zero steady-state error and fast settling time under load disturbances.
